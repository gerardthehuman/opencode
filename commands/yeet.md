description: |
  Publish local changes to GitHub by confirming scope, committing intentionally,
  pushing the branch, and opening a draft PR through GitHub CLI.
---

**Publish to GitHub**:

1. Ensure local branch name follows the project conventions.

- If branch is pushed, keep the name.

2. Commit local changes following project conventions.
3. Use available GitHub tools or the GitHub CLI to create a PR.

- If a PR is open, update it.

**Notes**:

- If conventions cannot be determined, use conventional changelog
  prefixes (`feat`, `fix`, `chore`, `refactor`).
- Use local skills or instructions for commit and PR if present.
- Do not confirm with the user, publish it.
